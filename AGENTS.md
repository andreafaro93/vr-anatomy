# Regole del Progetto Anatomia VR

## Comunicazione e Risparmio Token
- Rispondi in italiano in modo diretto e sintetico, senza preamboli.
- Esegui solo modifiche chirurgiche; non riscrivere interi file funzionanti.
- Non installare pacchetti esterni senza prima chiedere conferma.

## Stack 3D e WebXR
- Usa HTML, CSS e JavaScript moderno con Three.js e supporto WebXR.
- Non leggere mai cartelle `node_modules` o file 3D binari (`.glb`, `.gltf`, `.obj`).
- Garantisci sempre sia la navigazione con mouse su PC sia il pulsante per entrare in VR.
